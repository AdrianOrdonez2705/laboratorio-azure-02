# Prompt 04 - Actualizar el runbook

Revisa `docs/azure-deployment-runbook-template.md` y la evidencia disponible del laboratorio.

No modifiques archivos primero: identifica pasos desactualizados, nombres que deben personalizarse y verificaciones faltantes. No inventes comandos ejecutados, URLs, revisiones ni resultados.

Luego propone los cambios para que el runbook documente: preflight, tests, build, smoke test, escaneo, ACR, push, Container Apps, variables/secretos, probes, HTTPS, logs, version v2, rollback conceptual, evidencia y limpieza autorizada.
