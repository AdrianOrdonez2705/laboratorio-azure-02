# Prompt 03 - Diagnosticar un despliegue

Analiza el error que voy a pegar junto con el contexto del repositorio.

No modifiques archivos hasta identificar una causa probable y proponer una prueba que la confirme.

Separa el diagnostico en: aplicacion, Docker, ACR, autenticacion/autorizacion, Container Apps, ingress/puerto, variables/secretos y health probes. Solicita solo la evidencia que falte. Despues propone la correccion minima y explica como verificarla.
